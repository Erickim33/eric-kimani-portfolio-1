Hole

A messaging app focused on disappearing communication.

Web & Mobile
RoleFull-Stack Development
PlatformReact Native, Node.js
DatabaseMongoDB
The Idea

Messaging that doesn't need to stay permanent.

Hole was built around a simple concept: messaging that does not need to remain permanent. The application is designed around disappearing messages, creating a different kind of communication experience from traditional messaging platforms.

The project also explores how a messaging app can combine a simple interface with the technical systems needed to support real users and real conversations.

The Interface

Authentication through to real-time chat.

I worked on the mobile application interface, including the authentication screens, user setup, home experience, and chat screens — aiming for an experience that feels straightforward while supporting the functionality behind it.

  • Registration & login
  • Email verification
  • User profiles
  • Conversations & chat screens
  • Real-time interaction
  • Disappearing messages
Authentication & Backend

A real backend behind the interface.

One of the major parts of Hole has been developing its authentication system: registration, login, email OTP verification, password handling, and session management, with a verification flow that confirms a user's email before completing registration.

Hole is supported by a Node.js and Express backend, handling API routes, authentication flow, and the connection to MongoDB and Mongoose for user data and authentication records — plus Socket.io for real-time messaging, typing indicators, and seen states.
